figma2ui · system design

From Figma design to working UI, without paying the AI to read the design

figma2ui is a small helper that runs on the developer's machine. It converts the design itself, so the AI assistant only handles short messages. It works with Kiro, Claude Code, Cursor, and other AI tools.

Why this saves AI credits

AI assistants charge for everything they read and write. figma2ui keeps the bulky part away from them.

Conversion runs as code

Turning layers into components is done by a program, not by the AI. A program costs no credits.

Repeats are built once

A grid of similar cards becomes one component, used many times.

Work is split into chunks

Large screens are cut into sections, so the assistant opens only the part that needs attention.

Designs are remembered

An unchanged design is not downloaded from Figma again.

One helper, every AI tool

figma2ui speaks MCP, the open standard that AI tools use to connect to helpers. The same server is registered once in each tool, plus a short instruction file that tells the assistant the cheapest way to use it.

Kiro

  • Register in .kiro/settings/mcp.json
  • Instructions go in .kiro/steering/

Claude Code

  • Register with claude mcp add
  • Instructions install as a skill

Cursor

  • Register in .cursor/mcp.json
  • Instructions go in .cursor/rules/

Others

  • Windsurf, Codex, Gemini CLI, Claude Desktop
  • Instructions go in AGENTS.md or the tool's rules file

Output matches the project's tech stack

The stack is detected automatically. Web projects get ready code. Mobile and other projects get a compact blueprint that the assistant turns into native code, which costs more credits.

Where it stands today

Done

  • Server built, with 41 automated tests passing
  • Generated code accepted by the React, Vue, Svelte, Angular, and Tailwind build tools
  • Published on GitHub

Not yet verified

  • A full run on a real Figma design, with a visual comparison
  • Setup inside each AI tool. So far only the connection protocol was tested

Known limits

  • Needs a Figma Dev or Full seat for regular use. Other seats allow only a few designs per month
  • Figma Make files cannot be converted
  • Animations and app logic are still added by the assistant
